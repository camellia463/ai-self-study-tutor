# 迭代方案 v2.3 · 北极星指标"转化率" + 噱头放开

> 日期：2026-08-24
> 性质：对 v2.0-v2.2 的增量，定死产品北极星指标 = 学会→分数的转化率

---

## 一、北极星指标定死

**核心不是"学会"，是"学会→分数的转化率"。**

产品一句话叙事（slogan）：
> **不是让你学得更多，是让你学了的，都变成分。**

---

## 二、转化链 + 损耗点 + 功能映射

```
学习投入 → 学会 → 掌握率提升 → 做题正确率提升 → 分数提升
                ↑        ↑              ↑
              假学会    遗忘/不会迁移    熟练度/知识孤岛
```

| 损耗点 | 现象 | 堵它的功能 |
|---|---|---|
| 假学会 | 看懂≠学会 | 费曼检验（讲出来） |
| 不会迁移 | 原题会变式懵 | 真变式（结构/方法/情境） |
| 遗忘 | 学会但考试忘 | SM-2 间隔重复 |
| 熟练度不足 | 会做但慢/粗心 | 错因分类（粗心/半懂/盲区） |
| 知识孤岛 | 单点会综合不会 | 跨章节连接 |

**原则：每个功能必须对应堵一个损耗点，禁止无目的的功能堆叠。**

---

## 三、转化率量化模型（核心算法）

### 3.1 公式
```
整体掌握率 = Σ(各知识点掌握度) / 知识点总数

预估分数 = Σ(知识点分值权重 × 该知识点掌握度 / 100)

转化率 = 预估分数 / 理论满分（= Σ分值权重）
```

### 3.2 实时映射
- 学完一个知识点，掌握度变化 → 预估分数实时跳动
- 例：数量积（权重 8）掌握度 0%→80% → "掌握率 +80%，预估涨 6.4 分"

### 3.3 仪表盘展示
- 首页："知识掌握率 62% → 预估 512 分 → 距目标 18 分"
- 转化率对比："你的转化率 75% vs 平均 85% → 有假学会，费曼检验帮你补"

### 3.4 数据来源
- `score_weight`：已有（knowledge_point 表）
- `mastery`：已有（student_mastery 表）
- 只需新增一个"预估分计算服务"（纯函数，可单测）

## 四、两层转化率（更精确的定义）

1. **学习转化率**（知识层）：学了 → 掌握了（掌握率提升）
   - 损耗 = 假学会 → 堵 = 费曼检验
2. **考试转化率**（分数层）：掌握了 → 考出了（分数提升）
   - 损耗 = 遗忘/不会迁移/熟练度/孤岛 → 堵 = SM-2/真变式/错因分类/跨章节

两层合起来 = 从"投入"到"分数"的总转化率。
