## 〇、产品定位与北极星指标

### 0.1 一句话定位
**一个把"学会"直接转化为"分数"的 AI 自学提分系统：学生告诉 AI 目标和作息，AI 按「诊断→排课→教学→检验→复习→调控」闭环运转，核心交付不是"多刷题"，而是"学了的都变成分"。**

### 0.2 Slogan
> **不是让你学得更多，是让你学了的，都变成分。**

### 0.3 北极星指标（最核心，一切功能围绕它）
**学会 → 分数的转化率。**

- 知识掌握率提升：每个知识点掌握度 0→100% 的进度
- 转化率提升：掌握的这些，有多少真的变成分数

**检验"学会"的唯一硬标准**：① 能用自己的话讲出来（费曼）② 能迁移到没见过的新题（变式）。

## 二、核心概念：学会闭环 + 转化链

### 2.1 学会六环闭环
```
懂（理解为什么）→ 练（以练代学）→ 讲（费曼输出）→ 迁（真变式）→ 测（周测）→ 记（间隔重复）
```

### 2.2 转化链 + 5 损耗点（每个功能堵一个损耗点）

| 损耗点 | 现象 | 堵它的功能 |
|---|---|---|
| 假学会 | 看懂≠学会 | 费曼检验（讲出来） |
| 不会迁移 | 原题会变式懵 | 真变式（结构/方法/情境） |
| 遗忘 | 学会但考试忘 | SM-2 间隔重复 |
| 熟练度不足 | 会做但慢/粗心 | 错因分类（粗心/半懂/盲区） |
| 知识孤岛 | 单点会综合不会 | 跨章节连接 |

**纪律：新增任何功能，必须回答"它堵哪个损耗点"——答不上来就不做。**

### 2.3 两层转化率
1. **学习转化率**（知识层）：学了 → 掌握了（堵假学会）
2. **考试转化率**（分数层）：掌握了 → 考出了（堵遗忘/迁移/熟练/孤岛）

## 四、核心功能

### 4.1 目标设定明确化（E5 输入，最大改造）

**A. 目标建模（SMART）**
- `targetExam` 结构化下拉（高考/月考/期末/中考），自动算剩余天数
- 新增 `currentScore`（当前基线）→ `差距 = 目标分 - 当前分`
- 系统输出可感知承诺："你要在 N 天内涨 X 分 = 每天 Y 分，折合每天 Z 个知识点"

**B. 时间能量地图（生成周计划前必答）**
- 7×24 网格点选：❌固定不可用 / ✅可用 / ⚡黄金时间
- 默认规则：饭后 30min 低效（详见核心算法·能量模型）

**C. 节律排课（能量→任务映射）**
| 能量 | 触发 | 排什么 |
|---|---|---|
| ⚡高 | 运动后/早晨 | 攻克（新知识/难题/变式） |
| ✅中 | 一般空闲 | 练习（刷题巩固） |
| 🔋低 | 饭后30min | 复习（错题回访/SM-2） |

输出：精准到 30min 时间槽的时刻表。

**D. 定时提醒设置（统一在目标设定里配）**
- 每日复盘提醒时间（默认 21:00，可自定义）
- 学习开始提醒 / 超时休息提醒开关
- 所有提醒时间集中在目标设定页配置，成长档案的复盘提醒从这里读取（不重复设置）

### 4.2 周计划总调控（E5 核心）

**调控层 1：时间间隔与精度**
- 单块时长按学力自适应（25-45min 番茄钟）
- 每 block 绑定具体 `time_slot`

**调控层 2：未完成补偿调度（reschedule）**
- block `skipped` → 触发重排：
  1. 扫当天剩余高能量槽补
  2. 当天补不完 → 明天让位（降明天低优先级 block，插补学任务）
  3. 核心知识点（高权重×高薄弱）标记"不可跳过"
- 写 `adjust_history`，前端可视化"AI 怎么帮你追进度"

### 4.3 学会闭环（E2 攻克，核心）

每个知识点走四阶段学习流：
**前置回顾 → 概念讲解（含"为什么"+2D可视化）→ 例题精讲（跟着做）→ 练习（基础/常考/真变式）**

- **概念讲"为什么"**：是什么 → 为什么是这样 → 怎么做 → 怎么写（四段式）
- **可视化分级（漫画 vs 图像）**：叙事型概念（讲一个故事/过程）→ SVG 漫画分镜；直观型概念（一张图能看懂）→ 图像（2D 斜二测投影/函数图像/示意图），不用 3D（渲染易出问题），保证直观+零渲染错误
- **费曼输出检验**：学完练习题后，学生当老师讲"为什么"，AI 判断讲对/漏/错 → 追问补漏，讲明白才标记"真学会"
- **真变式**：结构/方法/情境三变（不是换数据），每题标注"变在哪"
- AI 三禁令：禁止直给答案、禁止无差别刷题、禁止排名羞辱

### 4.4 学力反向倒推（E1 → E5）

5 维认知各映射一个排课参数：
| 认知维度 | 反向倒推参数 |
|---|---|
| 加工速度 | 单块时长（快45min/慢25min） |
| 工作记忆 | SM-2 复习间隔（弱→缩短/强→拉长） |
| 流体推理 | 教法起点（强→演绎/弱→类比） |
| 认知灵活性 | 变式跨度（灵活→大跨度/僵化→小步） |
| 学习能力 | 单日推进速度 |

### 4.5 转化率引擎（新增，北极星指标可视化）

- 首页仪表盘："知识掌握率 62% → 预估 512 分 → 距目标 18 分"
- 实时映射：学完一个知识点，预估分跳动（"数量积掌握度 +80%，预估涨 6.4 分"）
- 转化率对比："你的转化率 75% vs 平均 85% → 有假学会，费曼检验帮你补"

### 4.6 其他功能
- **知识图谱可点击**：has_content 的知识点点进学习，无内容的展示前置依赖链
- **错题本/复习**：SM-2 + 错因三分类（已有）
- **极简账号**：用户名+密码（已有，token 持久化）

### 4.7 成长档案「知识档案柜」（新增，数据闭环最后一环）

**定位**：学生每天的学习数据 + 反思，全部沉淀成可回溯的成长轨迹。呼应舒大军体系"复盘"环节，把"复盘总结"产品化。

**四大组件**：

1. **定时提醒**：复盘提醒时间从目标设定里读取（默认 21:00），到点 AI 自动弹提示"该复盘了"
2. **数据反馈**：AI 自动汇总当天数据，直观展示（见下表）
3. **自我反思**：学生看到数据后写复盘（今天不足 + 明天怎么改）
4. **成长轨迹**：档案柜可视化（时间线视图 + 30 天趋势曲线）

**数据反馈指标（AI 自动汇总）**：
| 指标 | 来源 |
|---|---|
| 任务完成度 | 今日计划 done / total |
| 答题正确率 | 答对 / 总题数 |
| 错题数量 + 错因分布 | wrong_question 表 |
| 专注时长 | 实际学习分钟（learning_log actual_minutes） |
| 掌握度变化 | 今天涨了多少掌握度 |
| 预估分变化 | 今天预估分涨了多少（联动转化率引擎） |

**数据闭环价值**：复盘数据 → 反馈排课引擎（连续 3 天正确率低 → 明天降难度；专注度下降 → 建议增加休息）。

**趋势可视化**：正确率 / 专注时长 / 掌握度 / 预估分 四条 30 天曲线，让学生直观看到"自己真的在进步"。

## 五、核心算法

### 5.1 能量计算模型（可解释）
```
能量等级 E(t) = 昼夜节律基线 B(t) + 活动后效应 A(t) + 个体修正 P
```
- 基线 B(t)：7 时段模板（早晨+2 ~ 睡前-1）
- 活动效应 A(t)：运动后30-90min +2（BDNF激活）、饭后30-60min -2、脑疲劳 -1
- 个体修正 P：工作记忆弱→25min短块、加工速度快→45min长块

### 5.2 转化率量化模型
```
整体掌握率 = Σ(各知识点掌握度) / 知识点总数
预估分数 = Σ(知识点分值权重 × 掌握度/100)
转化率 = 预估分数 / 理论满分（Σ分值权重）
```
纯函数，可单测。

### 5.3 动态重排 reschedule
```
输入：当前计划 + 完成日志 + 时间能量地图
处理：skipped 任务 → 当天剩余高能量槽 → 明天让位 → 核心知识点不可跳过
输出：更新后的计划 + adjust_history 记录
```

### 5.4 费曼判定（无 LLM，规则判断，已确定）
- **确定无 LLM 密钥**，用纯规则判断
- 预置每个知识点的"关键点清单"，每个关键点配一组"关键词 + 同义词"
- 学生回答 → 中文分词 → 关键词命中匹配 → 命中率 ≥ 80% 即通过
- 追问针对**未命中**的关键点，用模板追问补漏
- 判定三维度：概念对不对 / 逻辑通不通（关键词因果链）/ 关键条件漏没漏（如 b≠0）

### 5.5 内容生产规范（可视化分级 + 生成策略）

**可视化分级：叙事型→漫画，直观型→图像**
| 类型 | 判断标准 | 例子 |
|---|---|---|
| 漫画分镜 | 叙事型：讲一个故事/过程，需分镜展开 | 向量有方向+大小（走路类比）、数量积合力效果 |
| 图像 | 直观型：一张图能看懂 | 函数单调性（图像升降）、向量夹角、斜二测坐标系 |

**内容生成策略（72h 内 24 知识点不手写）**
- 核心考点精做（函数概念/单调性/三角函数等高频考点，人工精做，质量最高）
- 非核心模板 + 数据半自动生成
- 数学题不纯模板生成（错因树需人工预标注）；概念讲解可模板化（what/why/how/符号 四段框架统一）

## 七、技术架构（四层 + 三层拆分）

```
前端层    React + Vite + TS + Zustand + TanStack Query
  ↓
安全网关  Helmet + Rate Limit + CORS 白名单 + zod 校验 + 请求体限流
  ↓
应用层    Controller（路由/校验）→ Service（业务/调度/转化率）→ Repository（数据访问）
  ↓
数据层    SQLite（WAL）+ node-cache 缓存
```

技术加分项：
- **决策可解释（Explainable Scheduling）**：每个排课决策带 `reason`，前端可查看
- **WebSocket 实时推送**：到点提醒、进度同步
- **调度算法纯函数模块化**：能量计算、优先级排序、重排、转化率计算各自独立可单测
- **数据可视化引擎**：能量热力图、知识图谱、学力雷达图
- **测试覆盖**：调度算法单测 + 全链路冒烟测试

## 八、网络安全（纵深防御）

1. **应用层**：Helmet 安全头 + express-rate-limit 限流 + 请求体大小限制 + zod 全路由校验
2. **认证层**：scrypt 密码哈希 + token 过期 + 登录失败次数限制（防撞库）
