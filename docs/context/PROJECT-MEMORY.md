## AI 高考冲刺系统（2026-08-23 立项，主线）

- **文档**：`AI 高考冲刺系统技术交接文档 v1.0`（2026-08-23，PRD+技术规格，作者李泽）。李泽要求先理解不操作，已消化。
- **目标**：120 天（D1=2026-08-24）从零冲刺 640 分（2026 真题验收）+ 交付 AI 高考管家 v1 + 题库引擎 v1。科配方：数132/英122/语115/物90/化90(赋)/政91(赋)。
- **架构铁律**：管家=Orchestrator 只排期/督促/记账/调整；工具=Agent 只干活输出 JSON；数据闭环（错题→诊断→变式→回测→漏洞清单→重排）是灵魂。计划制定官为 MVP 首个能力。
- **关键决策**：① 12 月底高二上期末考为中期检验点；② AI 大脑、v1 形态、启动方式待定；③ 止损线 D45<480→600、D90<540→550+；④ 每周日提交周时间表。
- **环境前提（2026-08-23 确认）**：李泽全天在家自学（不在学校场域），自驱力守护为核心职责。管家 = JARVIS 式全场景三域：学习域（周时间表/日程提醒/晚间固定复盘+全检测/不牢明日重学/进度护航）+ 生活域（运动前置/休息超时提醒/菜谱管家/起居）+ 工具域（遇困难自造工具、管家调度 Agent + 学习质检）。v0 休息提醒靠"状态上报"双向协议；数据中枢四类需扩 +食谱/日程；排期升级为生活节律排期。
- **衔接**：继承 8/19 舒大军七步闭环 + 8/17 提分机器五引擎（docs/ 下）；复用 eng-vocab（self-study-platform）、ai-ability-diagnosis（ability-diagnosis-v3）、刷题站（prototypes）。
- **用户偏好**：v0 人肉版先行验证（连续 2 周完成率 >70% 才进 v1）；督促机制比代码值钱；计划按真实可学习时长排，不按 6h/天满排。
