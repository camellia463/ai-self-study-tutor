## 修复：限流误伤登录态（17:53）

用户报"点知识图谱跳出来了，里面有很多进程，应该也挂了"。真根因：
- authLimiter 挂在整个 /api/auth 路径上，前端 App 启动调 /api/auth/me 校验登录态也被限流（429）
- App.tsx catch 无条件清 token，把 429（限流）当成 401（未登录）误踢
- 任何页面刷新几次就被踢回登录页

修复：
1. 后端 authLimiter 只挂 login/register 路由（auth.js 内）
2. App.tsx me catch 只在 err.message 含"未登录/登录已过期"时才清 token

教训：限流中间件不能挂在整个 router 级别，要精确到具体路由；前端 catch 不能对所有错误都做"清登录态"，要区分状态码/错误类型。
