## 攻克流程细化 + 零LLM追问方案（完成）

李泽提出三步流程，固化为攻克四步：学→练→圈→固
- 学：交互式图解讲明白
- 练：做题，做错触发错因提示树追问（引导不给答案）

- 三机制：选择题错因绑定 / 分步卡点检测 / 圈题解法
- 运行时零API，提示预生成（MVP手写，二期LLM离线生产+审核）
- 关键洞察：开放式对话追问才需要LLM，封闭场景不需要

## 变式出题规范（完成）

李泽核心洞察：变式 ≠ 换数据。
- 换数据（假变式）：1+1=2 → 2+2=4，只改数字，背的是套路
- 真变式：1+1=2 → 4-2=2，结构变了（加→减），底层逻辑"凑成2"不变
- 变式本质：核心逻辑不变，呈现结构变，逼学生懂方法不是记题样

配方法6种真变式：符号变/逆向变/缺项变/系数变/问法变/跨章变
出题规则：练/固环节覆盖≥3种结构变式，禁止连续换数字题，难度阶梯（符号易→缺项问法中→系数跨章难）

已更新 PRD（新增"出题核心规范：变式"章节）。
