## 一、核心命题：什么叫"学会"

### 1.1 第一性原理
**看懂 ≠ 学会**。搜题软件让人"看懂解析"，但看懂是被动识别，学会是主动建构。

检验"真学会"只有两个硬标准：
1. **能用自己的话讲出来**（费曼技巧）——讲不明白 = 没懂
2. **能迁移到没见过的新题**（变式迁移）——只会做原题 = 背答案

### 1.2 "学会"六环闭环

```
懂（理解为什么）→ 练（以练代学）→ 讲（费曼输出）→ 迁（真变式）→ 测（周测）→ 记（间隔重复）
```

| 环 | 现状 | 缺口 |
|---|---|---|
| 懂 | 有概念讲解 | 缺"为什么"（v2.1 已补 why 字段） |
| 练 | 有基础题 | ✅ |
| 讲 | ❌ 完全没有 | **"学会"的最硬检验，缺** |
| 迁 | 假变式（换数字） | **缺真变式** |
| 测 | 有周测 | ✅ |
| 记 | 有 SM-2 | ✅ |

**结论：产品核心差距是"讲"和"迁"两环，补上"能学会"才成立。**

## 二、补"讲"环 · 费曼输出检验（新增功能，核心）

### 2.1 交互流程
1. 学完一个知识点的练习题后，进入"讲给我听"环节
2. AI 出题："现在换你当老师，用自己的话讲：为什么 a·b=0 就等价于垂直？"
3. 学生文字输入（预留语音接口）
4. AI 判断：命中关键点 → 通过；漏了/错了 → 追问补漏
5. 讲明白 → 标记"真学会"，解锁真变式迁移题；讲不明白 → 再引导

### 2.2 判定维度
- 概念对不对（关键结论是否准确）
- 逻辑通不通（因果关系是否成立）
- 关键条件漏没漏（如"b≠0"这类边界）

### 2.3 技术实现
- **黑客松版（无 LLM）**：规则判断——预置每个知识点的"关键点清单"，学生回答做关键词/语义匹配，命中率达标即通过；追问用模板
- **有 LLM 接入**：直接让模型判断 + 生成个性化追问

### 2.4 数据模型
`learning_record` 新增 `feynman_passed`（boolean）、`feynman_gaps`（漏掉的关键点 JSON）

## 三、补"迁"环 · 真变式（v2.0 已提，此处落地）

变式三型，每道标注"变在哪"：
1. **结构变式**：已知↔求反过来（给结果反推条件）
2. **方法变式**：同一题换解题路径（坐标法 vs 几何法）
3. **情境变式**：几何题 → 物理力题 → 生活场景

`question` 新增 `variation_type` 字段（structure/method/context），错因树同步升级。

## 四、噱头扩展 · 围绕"学会"分层

### 第一梯队（强噱头 = 核心功能本身）

| 噱头 | 形式 | 为什么强 |
|---|---|---|
| 「你教 AI」费曼反转 ⭐ | 角色反转，学生当老师讲给 AI 听，AI 装学生追问 | 角色反转极有记忆点 + 是"学会"硬核检验，一石二鸟 |
| 「苏格拉底连环追问」 | AI 不答反问，连环逼学生自己想（对话流演示） | 展示"AI 引导不喂答案"，差异化叙事 |
| 「提分预言」 ⭐ | "照你每天 80% 完成率，30 天后预计涨 12 分"，每天实时更新 | 有话题性 + 有真实进度数据支撑 |

### 第二梯队（视觉噱头）

| 噱头 | 形式 |
|---|---|
| 「错误博物馆」 | 错题本升级成"博物馆"，每道错题一个展柜：错因+正确解法+防坑提示+复诊次数，把错题变成"成长证据" |
| 能量热力图 | 一周 7×48 时间槽能量热力图（保留 v2.1） |
| 追进度动画 | 任务被占用→AI 秒重排动画（保留 v2.1） |

### 第三梯队
- 数据背书（保留）

### 噱头筛选原则
- 噱头必须**服务"学会"或"排课"核心**，不为噱头而噱头
- 费曼反转是最高优先级——既是噱头又是核心，零浪费
